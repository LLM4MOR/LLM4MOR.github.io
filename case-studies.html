01

Multi-day vehicle routing

ns3084303

Problem description

A truck visits each of \(T\) locations once, with one stop per day. The goal is to minimize total travel distance.

The route must satisfy the following requirements. Each stop changes the truck's load by a fixed amount, and the load after each stop must stay at or below a prespecified capacity \(Q\). Some stops must precede others. The route closes with a leg from the final stop back to the first.

Variables and indices

Route arcs
\(x_{ij}\in\{0,1\}\) equals 1 if the route uses the directed arc from location \(i\) to location \(j\).
Visit days
\(y_{it}\in\{0,1\}\) equals 1 if location \(i\) is visited on day \(t\).
Vehicle load
\(f_t\in\mathbb R\) is the cumulative load after day \(t\), with \(f_0=0\). This benchmark imposes an upper bound only.
Index sets
\(S=\{1,\ldots,T\}\) indexes locations and visit days; \(S_0=S\cup\{0\}\) includes the initial day. Each pair \((a,b)\in\mathcal P\) requires visiting \(a\) before \(b\).
Parameters
\(Q\) is the vehicle capacity, \(a_i\) is the signed load change at location \(i\), and \(d_{ij}\) is the travel distance from location \(i\) to location \(j\).

Original formulation

\[ \begin{alignedat}{2} \min_{x,y,f}\quad &\sum_{(i,j)\in S\times S}d_{ij}x_{ij} & &\qquad \\[3pt] \text{s.t.}\quad &\sum_{j\in S}x_{ij}\ge1 & &\qquad \forall i\in S\quad\text{(1.1)}\\[3pt] &\sum_{i\in S}x_{ij}\ge1 & &\qquad \forall j\in S\quad\text{(1.2)}\\[3pt] &\sum_{t\in S}y_{it}=1 & &\qquad \forall i\in S\quad\text{(1.3)}\\[3pt] &\sum_{i\in S}y_{it}=1 & &\qquad \forall t\in S\quad\text{(1.4)}\\[3pt] &y_{s,0}=1 & &\qquad \text{(1.5)}\\[3pt] &\textcolor{#255ba8}{x_{ij}+y_{i,t-1}\le1+y_{jt}} & &\qquad \forall i,j\in S,\ t=2,\ldots,T\quad\text{(1.6)}\\[3pt] &\textcolor{#255ba8}{\sum_{t\in S}t\,y_{at}\le\sum_{t\in S}t\,y_{bt}} & &\qquad \forall(a,b)\in\mathcal P\quad\text{(1.7)}\\[3pt] &f_0=0 & &\qquad \text{(1.8)}\\[3pt] &f_t=f_{t-1}+\sum_{i\in S}a_i y_{it} & &\qquad \forall t\in S\quad\text{(1.9)}\\[3pt] &f_t\le Q & &\qquad \forall t\in S\quad\text{(1.10)}\\[3pt] &x_{ij}\in\{0,1\},\quad y_{it}\in\{0,1\} & &\qquad \forall i,j\in S,\ t\in S_0\\[3pt] &f_t\in\mathbb R & &\qquad \forall t\in S_0 \end{alignedat} \]

Why this formulation is difficult to solve

Many route-linking constraints. One constraint per arc and day requires \(T^2(T-1)\) rows.

Weak precedence constraint in the LP relaxation: \(\sum_{t\in S}t\,y_{at}\le\sum_{t\in S}t\,y_{bt}\).

Reformulation

1. Link visits by position

The original model uses one constraint per arc and day to ensure that a selected arc leads to the next day's stop:

\[ x_{ij}+y_{i,t-1}\le1+y_{jt}, \qquad\forall\,i,j\in S,\quad t=2,\ldots,T. \]

Let the continuous variable \(p_i\) be the day that stop \(i\) is visited, and let \(q_i\) be the next visit day: \(p_i+1\) if \(p_i<T\), and day 1 if \(p_i=T\).

\[ \begin{alignedat}{2} p_i &= \sum_{t\in S}t\,y_{it}, &\qquad &\forall\,i\in S, \\[6pt] q_i &= p_i+1-Ty_{iT}, &\qquad &\forall\,i\in S. \end{alignedat} \]

We only need two bounds per arc to ensure that a selected arc leads to the next day's stop:

\[ \lvert p_j-q_i\rvert\le(T-1)(1-x_{ij}), \qquad\forall\,i,j\in S,\quad i\ne j. \]

Selecting \((i,j)\) sets the right-hand side to zero, so stop \(j\) must be visited on day \(q_i\). With nonnegative travel distances, this replacement preserves the optimal value.

Arc-linking rows · \(T^2(T-1)\to2T(T-1)\)
15,000 → 1,200
New position variables and defining rows · \(T\) of each
25 of each

2. Strengthen precedence with cumulative visits

The original constraint (1.7) compares the visit days of \(a\) and \(b\). When the visit indicators are binary, the stops are visited on distinct days, so \(a\) must come before \(b\). This means that, by any day \(t\), if the truck has visited \(b\), it must already have visited \(a\) by day \(t-1\). The cumulative sums in the following constraints express this requirement:

Original · Compare visit days
\(\displaystyle\sum_{t\in S}t\,y_{at}\le\sum_{t\in S}t\,y_{bt},\) \(\forall\,(a,b)\in\mathcal P\)
⇔Integer equivalence
Reformulated · Cumulative visits
\(\displaystyle\sum_{u=1}^{t}y_{bu}\le\sum_{u=1}^{t-1}y_{au},\) \(\forall\,(a,b)\in\mathcal P,\quad \forall\,t\in S\)

The cumulative constraints preserve the feasible visit orders when the visit indicators are binary. Summing these inequalities over \(t\) gives \(1+\sum_{t\in S}t\,y_{at}\le\sum_{t\in S}t\,y_{bt}\), which strengthens the LP relaxation.

Module placement on a grid

ns3025225

Problem description

The problem is to place unit modules on a grid with \(H\) rows and \(W\) columns. The modules are organized into \(L\) groups (called layers), each containing \(B\) modules. In every layer, module \(j\) connects to port \(j\), with ports numbered from left to right along the bottom edge. The goal is to minimize the largest absolute horizontal offset.

The placement must satisfy the following requirements. Each module occupies one cell, and no two modules share a cell. Modules in the same layer must stay close in height. Each layer has a height cap, and each module has a limit on how far left it can sit from its port.

Variables and indices

Cell placement
\(p_{ijmn}\in\{0,1\}\) equals 1 if module \(j\) in layer \(i\) occupies row \(m\) and column \(n\).
Distance bound
\(M\in\mathbb R\) bounds the absolute horizontal offset of every module.
Index sets
Layers \(i\in I=\{1,\ldots,L\}\), modules \(j,k\in J=\{1,\ldots,B\}\) in port order within each layer, rows \(m\in R=\{1,\ldots,H\}\), and columns \(n\in C=\{1,\ldots,W\}\).
Parameters
\(s\) is the maximum within-layer row span, and \(D\) is the upper bound on the signed horizontal offset. Layer \(i\) has a row cap of \(is\). Port \(j\) has horizontal coordinate \(a_j=\dfrac{Wj}{B+1}\), and \(d_{jn}=a_j-\left(n-\dfrac{1}{2}\right)\) is the signed horizontal offset from the center of column \(n\) to that port.

Vertical position and signed offset of a module

Let \(y_{ij}\) denote the vertical position of module \(j\) in layer \(i\), and let \(q_{ij}\) denote its signed horizontal offset from port \(j\). When the placement variables are binary, each module occupies exactly one cell, so \(y_{ij}\) and \(q_{ij}\) are given by:

\[ \begin{alignedat}{2} y_{ij} &= \sum_{(m,n)\in R\times C}m\,p_{ijmn}, &\qquad &\forall\,(i,j)\in I\times J, \\[6pt] q_{ij} &= \sum_{(m,n)\in R\times C}d_{jn}p_{ijmn}, &\qquad &\forall\,(i,j)\in I\times J. \end{alignedat} \]

Original formulation

\[ \begin{alignedat}{2} \min_{p,M}\quad &M & &\qquad \\[3pt] \text{s.t.}\quad &\sum_{(m,n)\in R\times C}p_{ijmn}\le1 & &\qquad \forall(i,j)\in I\times J\quad\text{(2.1)}\\[3pt] &\sum_{(i,j)\in I\times J}p_{ijmn}\le1 & &\qquad \forall(m,n)\in R\times C\quad\text{(2.2)}\\[3pt] &\sum_{(i,j)\in I\times J}\sum_{(m,n)\in R\times C}p_{ijmn}=LB & &\qquad \text{(2.3)}\\[3pt] &\textcolor{#255ba8}{M\ge d_{jn}p_{ijmn}} & &\qquad \forall(i,j,m,n)\in I\times J\times R\times C\quad\text{(2.4)}\\[3pt] &\textcolor{#255ba8}{M\ge-d_{jn}p_{ijmn}} & &\qquad \forall(i,j,m,n)\in I\times J\times R\times C\quad\text{(2.5)}\\[3pt] &q_{ij}\le D & &\qquad \forall(i,j)\in I\times J\quad\text{(2.6)}\\[3pt] &\textcolor{#255ba8}{-s\le y_{ij}-y_{ik}\le s} & &\qquad \forall i\in I,\ j,k\in J,\ j<k\quad\text{(2.7)}\\[3pt] &m\,p_{ijmn}\le is & &\qquad \forall(i,j,m,n)\in I\times J\times R\times C\quad\text{(2.8)}\\[3pt] &p_{ijmn}\in\{0,1\} & &\qquad \forall(i,j,m,n)\in I\times J\times R\times C\\[3pt] &M\in\mathbb R. & &\qquad \end{alignedat} \]

Why this formulation is difficult to solve

Large model. \(\mathcal O(LBHW)\) variables and \(\mathcal O(LBHW+LB^2)\) constraints: offset bounds for every candidate cell and row span constraints for every pair of modules in a layer.

Reformulation

1. Use one offset bound per module

The original offset bounds (2.4) and (2.5) are imposed separately for every candidate cell. Since each module occupies exactly one cell, its absolute horizontal offset can be expressed as a weighted sum, giving one bound for each \((i,j)\in I\times J\):

Original · Two bounds per candidate cell
\(M\ge d_{jn}p_{ijmn},\quad M\ge -d_{jn}p_{ijmn},\) \(\forall\,(i,j,m,n)\in I\times J\times R\times C\)
⇔Integer equivalence
Reformulated · Sum over cells
\(\displaystyle M\ge\sum_{(m,n)\in R\times C}|d_{jn}|p_{ijmn},\) \(\forall\,(i,j)\in I\times J\)

This replacement is equivalent to (2.4)–(2.5) when the placement variables are binary, since each module is assigned to exactly one cell. In the LP relaxation, nonnegativity of \(p_{ijmn}\) ensures that the weighted-sum bound implies every original cell-level bound. It therefore strengthens the relaxation while reducing the offset constraints to one per module.

Distance rows · \(\mathcal O(LBHW)\to\mathcal O(LB)\)
211,250 → 325

2. Use one shared interval per layer

The original row span constraints (2.7) require any two modules in the same layer to be at most \(s\) rows apart. Equivalently, their vertical positions lie in one interval of length \(s\).

To describe this interval, introduce a continuous variable \(b_i\) for its lower endpoint in layer \(i\). Each module's vertical position is then bounded between \(b_i\) and \(b_i+s\), giving the following constraints:

Original · Compare module pairs
\(-s\le y_{ij}-y_{ik}\le s,\) \(\forall\,i\in I,\quad \forall\,j,k\in J,\ j<k\)
⇔Equivalent row values
Reformulated · Bound each module row
\(b_i\le y_{ij}\le b_i+s,\) \(\forall\,(i,j)\in I\times J\)
\(b_i\in\mathbb R,\) \(\forall\,i\in I\)

These bounds ensure that any two modules in a layer are at most \(s\) rows apart. Conversely, when the original pairwise constraints hold, choosing \(b_i\) as the lowest vertical position among the modules gives a valid interval. The reformulation therefore preserves the row span requirement with two bounds per module.

20,800 → 650
